# MoveWell Physiotherapy Centre — 100 Websites Challenge #06

Move Better, Live Better. Multi-page physiotherapy centre website (HTML/CSS/JS) with real photos in `images/`, a Mobility Self-Check widget, and a full multi-step online booking system (MW-XXXXXX confirmation references, WhatsApp).

Part of the **100 Websites Challenge** by Abdullah Mahmood Official — one new business website every day.

## Pages

- `index.html` → Home (hero, treatments, therapists, self-check, reviews)
- `about.html` → Our story, approach, clinic gallery
- `services.html` → 8 treatments with PKR prices
- `therapists.html` → Physiotherapist profiles with hours
- `gallery.html` → Clinic photo gallery
- `appointment.html` → Multi-step online booking
- `contact.html` → Address, phone/WhatsApp, hours, form

## Tech

Plain HTML, CSS and JavaScript — shared `css/style.css` and `js/` scripts, no build step. Just open `index.html` or serve the folder with any static server.
